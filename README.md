# FORMA INTERIORS

Демонстрационный одностраничный сайт интерьерной студии. Стек: HTML5, CSS3 и vanilla JavaScript; без сборки, библиотек, CMS и backend. Откройте index.html в браузере или разместите папку на статическом хостинге.

## Live Demo

https://robdiezz.github.io/forma-interiors/

## Состав страницы

Header, Hero, «Проекты», «Услуги», «О студии», «Этапы работы», FAQ, финальная секция «Обсудить проект» с формой и информационными контактами, Footer. Реальных контактов, цен, отзывов, наград и сведений о выполненных заказах нет.

## Навигация и адаптивность

Все переходы используют настоящие href: #projects, #services, #about, #stages, #faq, #contacts, #inquiry. Логотипы и «Наверх» ведут к #top. CSS обеспечивает плавную прокрутку, prefers-reduced-motion отключает её и анимации.

С JavaScript мобильное меню открывается burger-кнопкой, поддерживает Tab/Shift+Tab и Escape и закрывается после перехода. Без JavaScript мобильная навигация показана в Header как обычный список ссылок; burger скрыт. На desktop внешний вид одинаков. Проверены 1920, 1440, 1024, 768, 390 и 360 px.

## FAQ и демонстрационная форма

FAQ: первый вопрос открыт по умолчанию, одновременно можно открыть один ответ. Используются button, aria-expanded, aria-controls и подписанные области ответов. Доступны мышь, Enter и Space. Без JavaScript все ответы видны.

Форма проверяет имя, непустой телефон/Telegram, согласие и положительную площадь, если она указана. Формат контакта намеренно не усложнён. Ошибки связаны через aria-describedby и aria-invalid; фокус переводится на первое ошибочное поле. Успешная проверка объявляется через aria-live, поля очищаются.

Данные никуда не отправляются и не сохраняются кодом сайта. Нет fetch/AJAX, аналитики или внешнего сервиса. Без JavaScript кнопка отправки отключена. Реальный механизм отправки нужно подключать отдельно.

## Изображения

Пять исходных JPEG сохранены. Для каждой фотографии подготовлены WebP и адаптивные JPEG fallback; picture/srcset/sizes учитывают ширину контейнера и кадрирование object-fit. Изображения и CSS-кадрирование не заменялись. Hero имеет fetchpriority=high и корректные размеры 2200×1650; остальные фотографии загружаются лениво.

Ширины вариантов:

- Hero: 640, 960, 1440, 2200 px.
- LIGHT HOUSE и TERRA: 640, 960, 1440, 1800 px.
- MONO: 640, 960, 1200 px.
- О студии: 640, 960, 1440, 1600 px.

Исходные пять JPEG: 2,34 МБ. Пять WebP в максимальном размере: 1,80 МБ. В проверенном браузере при DPR=1 суммарная загрузка пяти фотографий составляет около 0,31 МБ на 360/390 px, 1,03 МБ на 1440 px и 1,33 МБ на 1920 px. При другом DPR браузер выбирает другие варианты. Вся папка изображений, включая все размеры, форматы и сохранённые оригиналы, занимает 8,42 МБ; это объём хранения, а не загрузка одной страницы.

## Техническое состояние

Контраст маленького каменного текста и hover Header — 4,60:1; границ полей — 3,22:1. Крупный акцент --stone сохранён. Локальный градиент под подписью Hero даёт не менее 6,02:1 в проверенных кадрах. Подтверждённо неиспользуемые стили удалённого диалога и brand-dot удалены.

Повторно проверены геометрия утверждённых секций, меню, hash-навигация с JavaScript и без него, изображения и JPEG fallback, FAQ, форма, фокус, console и reduced motion. Canonical указывает на опубликованную версию сайта: https://robdiezz.github.io/forma-interiors/. Проверки выполнены в Edge/Chromium; физические мобильные устройства и Safari/Firefox отдельно не проверялись.

## Code structure

- `index.html` — структура и контент страницы.
- `css/style.css` — дизайн-система, layout и адаптивные стили.
- `js/main.js` — навигация, мобильное меню, FAQ и демонстрационная форма.
- `assets/images/` — исходные и адаптивные изображения.

В HTML, CSS и JavaScript добавлены комментарии, которые облегчают дальнейшее редактирование и передачу проекта другому разработчику.
